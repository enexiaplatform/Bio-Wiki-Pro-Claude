## Intended decision use

Help a professional separate observations, hypotheses, evidence, unresolved
questions, affected scope, ownership, and the next authorized decision. The
workflow must not authorize invalidation, additional testing, disposition,
authority reporting, CAPA closure, or release.

## Required reviewer roles

1. Editorial reviewer — traceability, clarity, claim strength, scenario labeling,
   source identifiers, links, limitations, and consistency across assets.
2. Qualified laboratory investigation reviewer — Phase I/II reasoning,
   additional-testing boundaries, data handling, evidence sufficiency, and
   quality-unit decision ownership.
3. Microbiology or sterility reviewer only if those sections remain — confirm
   that Atlas supplies questions rather than unlicensed method criteria.

Names must not be published without permission. Appointment or approval
evidence must be retained outside the public metadata.

## Critical review checklist

- [ ] Every material FDA statement is within the guidance's stated scope or is
      clearly labeled as an adaptation.
- [ ] Guidance, regulation, registered specification, compendial requirement,
      approved procedure, and Atlas recommendation are not conflated.
- [ ] No universal closure time, retest count, incubation condition,
      invalidation criterion, or authority-reporting rule is asserted.
- [ ] Passing additional results never erase an unexplained original OOS.
- [ ] Retest, resample, replicate, averaging, and outlier concepts remain
      distinct.
- [ ] Microbiology and sterility prompts require current approved/licensed
      sources and qualified review.
- [ ] Fictional facts are visibly fictional and are not framed as benchmarks.
- [ ] The blank workbook cannot show controlled readiness when required evidence
      or review is missing.
- [ ] The completed example does not contain client data or imply approval.
- [ ] PDF, lesson, quiz, README, and workbooks state the same decision boundary.

Any unchecked item is a critical release blocker.

## Usability acceptance

- [ ] A user can state the decision question in under two minutes.
- [ ] A user can identify the source and limitation behind each material rule.
- [ ] A user can enter an observation without prematurely labeling a cause.
- [ ] A user can distinguish evidence held from evidence required.
- [ ] A user can identify the authorized next owner.
- [ ] A user can complete the fictional example comparison without copying its
      facts into a live record.
- [ ] Workbook validation, formulas, required sheets, and sign-off fields open
      correctly in supported spreadsheet software.
