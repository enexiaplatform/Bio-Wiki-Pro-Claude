# Pharma API Starting Material & Input Control — 1.0 Review Packet

Status: `under-review`  
Content version: `1.0.0-review`

## Review scope

Review the lesson, guide, blank workbook and fictional example for scientific accuracy, route-boundary logic, supplier-chain realism, analytical/QC usability, quality governance and regulatory CMC limitations.

## Required reviewers

- Synthetic process development / API CMC
- Supplier quality and supply-chain quality
- API analytical development / QC
- Manufacturing science or validation
- Quality Unit
- Regulatory CMC

## Critical fail conditions

- Any single-factor starting-material acceptance shortcut
- Any invented chemistry, impurity conclusion, supplier approval, specification, method, limit or filing outcome
- Any workbook state that implies approval or batch disposition
- Missing source, limitation, evidence locator, accountable action or change impact
- Broken workbook, formula error or absent required sheet

## Acceptance evidence required

Record reviewer role, scope, date, corrections, unresolved issues and disposition. Product-level promotion remains blocked until score ≥85, critical fails are closed, qualified review is recorded and a permissioned real case demonstrates decision usefulness.
