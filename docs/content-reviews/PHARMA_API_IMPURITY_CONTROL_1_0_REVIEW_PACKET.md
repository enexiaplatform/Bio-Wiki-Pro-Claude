## Review scope

Review the Academy lesson, guide, blank workbook and fictional example as one evidence-to-working-file package for small-molecule API process development, impurity fate/purge and control placement.

## Critical review checklist

- [ ] Scope stays with the defined small-molecule API, route/process version, lifecycle stage, sites/scales and markets.
- [ ] No route, chemistry, process setting, method, impurity identity, acceptable intake, specification or authorization is invented.
- [ ] Predicted, observed and confirmed impurity identity are distinguishable.
- [ ] Non-detect, reporting boundary, analytical capability, sampling and comparability limitations are preserved.
- [ ] The observed-ratio formula cannot be read as a validated or transferable purge factor.
- [ ] Organic, residual-solvent, elemental and mutagenic impurity decisions remain separate where applicable.
- [ ] Process understanding, analytical suitability, safety/qualification, specification, validation, filing and disposition remain distinct decisions.
- [ ] Starting-material and supplier evidence does not overstate Q11/Q7 applicability or acceptance.
- [ ] Change assessment reopens affected origin, fate, method, control, validation and filing questions.
- [ ] Required reviewer roles and decision authority are explicit.

## Workbook usability acceptance

- [ ] All twelve sheets open and key instructions are visible at normal zoom.
- [ ] Editable categorical fields have validation lists.
- [ ] Formula cells are protected from casual overwrite where supported.
- [ ] Formula-error scan is clean.
- [ ] Blank file fails closed as `Evidence required`.
- [ ] Fictional example remains `Qualified review required` or `Evidence required`; it never becomes approval.
- [ ] Source URLs, version, limitations and review/sign-off fields are present.
