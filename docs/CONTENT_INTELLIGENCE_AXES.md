# Atlas End-to-End Content Intelligence Axes

Last audited: 2026-08-11

`PRODUCT_SOURCE_OF_TRUTH.md` remains canonical. This matrix describes four content and product-facing axes across three priority lifecycle domains. Public/SEO is a distribution axis, not a fourth paid product; the commercial architecture remains Quality Lab Blueprint, Atlas Pro and Career Blueprint.

| Lifecycle | Quality Lab Blueprint | Atlas Pro | Career Blueprint | Public / SEO |
| --- | --- | --- | --- | --- |
| Biopharma | Decision Package context is carried through planner, discovery, results and lineage. It is evidence/discovery context only and displays `Domain Pack not verified`. | Three stage-ordered packages connect cell/material/upstream through downstream/analytics/formulation and validation/comparability/transfer. | The Biopharma domain track maps package competencies to evidence activities and thirteen-week actions. Activity completion is not competence verification. | The Biopharma hub and package guides hand off directly to the matching Blueprint context, Pro stage and Career track. |
| Pharma/API | Package context is available without adding API calculations, recommendations or Compiler rules. | Four stage-ordered packages connect route/input control through reaction/work-up, isolation/solid-state/impurity and analytical/commercial lifecycle. | The Pharma/API track maps role families, competency gaps and evidence activities without importing Quality Lab project state. | The Pharma/API hub and package guides expose the same three contextual handoffs. |
| Pharmaceutical Drug Product | Package context remains non-executable. The framework is general; OSD examples are synthetic and bounded. | Four stage-ordered packages connect formulation/material attributes through unit operations, analytical/release/stability/packaging and validation/change. | The Drug Product track uses package competency/evidence mapping and keeps dosage-form applicability explicit. | The Drug Product hub and decision guides link to the matching Blueprint, Pro and Career destinations. |

## Enforced boundaries

- Every Decision Package must register a public guide, Pro lesson, bounded workflow or tool, and working asset.
- Every existing artifact-plan reference must resolve to an asset registered on the same package.
- Public guide handoffs preserve the `decisionPackageId` into Blueprint and Pro routes and select the matching Career domain.
- Quality Lab does not compile Biopharma, API or Drug Product recommendations. The executable Domain Pack remains non-sterile pharmaceutical microbiology and is not verified.
- Editorial review does not imply SME review, validated competence, product/site approval, Gate 1 completion or dosage-form applicability.
