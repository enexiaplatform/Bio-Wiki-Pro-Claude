# Pharma API Reaction, Work-up & Scale-up Evidence Map

Version: `1.0.0-review`
Status: `editorial-reviewed`
Decision state: `Evidence required` or `Qualified review required` only

This working pack connects route version, reaction, quench, phase split, hold,
sampling, equipment differences, scale-up observations and receiving-site
questions. It is not a reaction recipe, batch record, process range, purge
factor, specification, validation conclusion or manufacturing authorization.

## Files

- `pharma-api-reaction-scale-up-guide.md` — bounded workflow and review logic.
- `pharma-api-reaction-scale-up-blank.csv` — blank evidence register.
- `pharma-api-reaction-scale-up-fictional-example.md` — synthetic worked example;
  not a process or regulatory precedent.

## Controlled sources

`ICH-Q8-R2`, `ICH-Q9-R1`, `ICH-Q10`, `ICH-Q11`, `FDA-PROCESS-VALIDATION-2011`.

## Reviewer boundary

Process chemistry, chemical/process engineering, manufacturing science,
analytical development, validation, quality and regulatory CMC reviewers must
confirm the applicable process version, site, market, source edition and
limitations before using any record.
