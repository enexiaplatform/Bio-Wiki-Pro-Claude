# Decision-led Statistics & Process Evidence Map

Version: `1.0.0-review`
Status: `editorial-reviewed`
Decision state: `Evidence required` or `Qualified review required` only

This working pack connects a defined decision to data lineage, measurement
system, design or analysis, assumptions, diagnostics, uncertainty,
contradictions and lifecycle use. It does not provide universal model rules,
CPP declarations, capability criteria, control limits or validation conclusions.

## Files

- `decision-led-statistics-evidence-map-guide.md` — bounded analysis and review
  workflow.
- `decision-led-statistics-evidence-map-blank.csv` — blank data-to-decision
  evidence register.
- `decision-led-statistics-evidence-map-fictional-example.md` — synthetic
  process-evidence example with open questions.

## Controlled sources

`ICH-Q8-R2`, `ICH-Q9-R1`, `ICH-Q10`, `FDA-DI-2018`,
`FDA-PROCESS-VALIDATION-2011`.

## Reviewer boundary

Applied statistics/process data science, the accountable domain scientist,
measurement-system owner, data-integrity reviewer and quality role must review
the exact decision, dataset and model-use boundary. Editorial review does not
constitute SME approval or controlled release.
