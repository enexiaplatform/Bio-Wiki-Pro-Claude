# Analytical Lifecycle Evidence Map

Version: `1.0.0-review`
Status: `editorial-reviewed`
Decision state: `Evidence required` or `Qualified review required` only

This cross-product working pack connects analytical purpose, intended use,
attribute, analytical target profile, procedure capability, validation,
transfer and lifecycle change. It is not a product method, specification,
validation protocol, transfer acceptance, filing position or batch decision.

## Files

- `analytical-lifecycle-evidence-map-guide.md` — source-bounded workflow and
  review prompts.
- `analytical-lifecycle-evidence-map-blank.csv` — blank lifecycle evidence
  register.
- `analytical-lifecycle-evidence-map-fictional-example.md` — bounded fictional
  example showing unresolved evidence and accountable review.

## Controlled sources

`ICH-Q2-R2`, `ICH-Q14`, `ICH-Q9-R1`, `ICH-Q10`.

## Reviewer boundary

Analytical development, measurement science/statistics, QC, validation,
quality and regulatory CMC roles must confirm product, matrix, intended use,
market, source edition and lifecycle applicability. Editorial review does not
constitute SME approval or controlled release.
