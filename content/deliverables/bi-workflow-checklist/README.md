# BI Workflow Checklist — Start Here

A working pack for using biological indicators (BIs) to validate and routinely
monitor sterilization processes — moist heat (autoclaves), dry heat, VHP
bio-decontamination, and EtO. It turns the BI lifecycle — selection, receipt,
placement, exposure, incubation, reading, and failure investigation — into a
step-by-step checklist with a run log you can open in Excel and use today.

## Who it's for

- QC microbiology analysts running autoclave and sterilizer BI challenges.
- Validation engineers placing BIs during cycle PQ and requalification.
- QA reviewers who must disposition loads after a positive BI.
- Small labs and startups building a sterilization monitoring program from
  scratch.

## What's inside

1. **bi-workflow-checklist.md** (renders to PDF) — the main guide. Eleven
   sections: regulatory basis (ISO 11138 series, USP <55>, USP <1229>,
   ISO 17665, ISO 11135, PDA TR 1 and TR 51), BI selection by process and
   format, receiving/CoA review and D-value verification, validation placement
   strategy, routine monitoring with controls, incubation and reading rules,
   a positive-BI investigation decision tree, D-value method overview
   (survivor curve vs Limited Spearman-Karber), documentation expectations,
   inspector questions and common findings, and a fully worked fictional
   positive-BI investigation. Includes printable checklists, fill-in
   specification fields, and sign-off blocks.
2. **bi-run-log.csv** (opens in Excel) — one row per BI or control per run.
   Columns: Run ID, Date, Sterilizer ID, Cycle Type, Cycle Parameters, BI Lot,
   Organism, D-value, Population, Carrier Type, Location in Load, Control
   Type, Exposure Result, Control Result, Incubation Start/End, Read By,
   Disposition, Deviation Ref. Five example rows show a normal released run,
   its positive and negative controls, a growth-positive run linked to a
   deviation, and a pre-vacuum run — mirroring the worked example in the guide.

## Recommended order of use

1. Read the guide end to end once — especially Section 11 (worked example).
2. Adapt the BI specification fill-in fields (Section 2.2) to your approved
   cycles and have QA approve them.
3. Use Section 3 checklists for your next BI lot receipt.
4. Use Sections 5–6 as your per-run checklist, logging every run in the CSV.
5. Keep Section 7 (investigation decision tree) at hand for any positive.
