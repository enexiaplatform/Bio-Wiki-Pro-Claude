# Pharma API Process & Impurity Control Evidence Map

Version: `1.0.0-review`  
Review status: `editorial-reviewed`

## Start here

This package turns one small-molecule API process-development, impurity fate/purge, control-placement or lifecycle-change question into a traceable cross-functional evidence record. It is an educational working system, not a chemical-development protocol, specification, submission or controlled site record.

Use the files in this order:

1. Read the guide and freeze one product, route/process version, change or control decision.
2. Copy the blank workbook into the controlled project location.
3. Map route inputs and unit operations before entering impurity observations.
4. Record observed fate only when stages, units/basis, sampling and method capability are comparable.
5. Link every material claim to an Evidence ID and every gap to an action/owner.
6. Route the package through the required qualified reviewers and preserve disagreement.

## Decision boundary

The workbook can organize route, input, unit-operation, impurity-origin, observed-fate, analytical-capability and control-placement evidence. It supplies no chemical route, material, process condition, impurity identity, purge factor, acceptable intake, specification, validation conclusion, filing decision or batch disposition.

An observed ratio is not a transferable purge factor. A result below a reporting boundary is not proof of zero material or complete removal. Decision owner and qualified reviewers retain authority.

The blank workbook fails closed as `Evidence required`. Structural completion can only reach `Qualified review required`; it cannot approve a route, process, control strategy or product.

## Required reviewer roles

- synthetic process development / process chemistry;
- chemical or process engineering and scale-up;
- analytical development and impurity characterization;
- toxicology or impurity-safety specialist when applicable;
- API QC and data integrity;
- Quality Unit / validation / technology transfer as applicable;
- API regulatory CMC.

## Applicability and limitations

Apply only to the defined small-molecule drug substance, route/process version, materials, sites, scales, equipment, methods, lifecycle stage, markets and decision. Adaptation and qualified review are required before controlled use. Fermentation-derived APIs, peptides, oligonucleotides, radiopharmaceuticals, highly potent compounds, continuous manufacturing and other modalities can require different evidence and reviewers.

Do not upload confidential chemistry, batch, supplier, method, specification or filing information into an unapproved system.
