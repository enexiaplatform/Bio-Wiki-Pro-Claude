# Biopharma Upstream Control Evidence Map — Start Here

This package helps a cross-functional Biopharma team connect product-quality
attributes, cell substrate, raw materials, upstream process parameters,
performance indicators, evidence strength, controls, and lifecycle triggers.

**Package version:** 1.0.0-review

**Review status:** Editorial-reviewed; not SME-approved

**Decision owner:** The authorized product, process, quality, and regulatory owners — not Atlas

## Package contents

1. `biopharma-upstream-control-guide.pdf` — decision workflow, terminology,
   evidence-strength model, and review boundaries.
2. `biopharma-upstream-control-v1.xlsx` — blank working file with validation,
   formulas, sources, limitations, and sign-off fields.
3. `biopharma-upstream-control-v1-fictional-example.xlsx` — completed fictional
   CHO process example demonstrating how to preserve uncertainty and open review.

## Recommended order

1. Read the guide and confirm that the product and modality are in scope.
2. Write one decision in `Decision Brief`; do not begin with a generic parameter list.
3. Map product attributes before proposing process relationships.
4. Record product/process evidence and contradictory findings in the evidence register.
5. Assign controls and lifecycle triggers only after documenting the relationship basis.
6. Review every formula-driven `Incomplete` or `Review required` flag.
7. Export or transfer the reviewed content into the site's controlled system.

## Important boundary

The workbook contains no generic numeric operating range, CPP designation,
design space, process capability claim, PPQ criterion, specification, or batch
disposition rule. Every product-specific value requires controlled provenance
and qualified review.
