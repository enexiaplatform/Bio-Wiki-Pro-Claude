# HPLC System Suitability

System suitability testing (SST) is the gate at the start of every
chromatographic run: it proves the **whole system** — column, mobile phase,
pump, detector, integration software — is performing adequately **today**,
before you trust a single sample result. The governing compendial reference is
**USP &lt;621&gt; Chromatography**, which defines the parameters and how they
are calculated.

SST is deliberately confused with method validation. Validation proves once,
formally, that a method is fit for purpose. SST is the routine, per-run check
that the validated method is running correctly right now. A validated method on
a degraded column fails SST; an unvalidated method that passes SST is still not
validated.

## The Core SST Parameters

| Parameter | What it measures | Typical acceptance basis |
| --- | --- | --- |
| Resolution (Rs) | Separation between two adjacent peaks, e.g. analyte and nearest impurity | Rs ≥ 1.5–2.0 commonly specified for quantitative work; monograph-defined |
| Theoretical plates (N) | Column efficiency | Minimum N stated in the monograph or method |
| Tailing factor (T) | Peak symmetry at 5% of peak height | T ≤ 2.0 commonly specified; monograph-defined |
| %RSD of replicate standard injections | Injection and system precision | Per monograph; USP &lt;621&gt; ties replicate count to the limit |
| Capacity / retention factor (k) | Retention strength of the analyte | Where specified in the monograph |

The acceptance criteria live in the **monograph or the validated method**, not
in a generic template. USP &lt;621&gt; provides the calculation conventions and
default replicate rules; individual monographs set the actual limits.

## The %RSD Rule in USP &lt;621&gt;

One detail analysts routinely get wrong: USP &lt;621&gt; links the number of
replicate standard injections to the stringency of the precision requirement.
Unless the monograph says otherwise:

- if the %RSD requirement is **2.0% or less**, data from **five** replicate
  injections are used;
- if the %RSD requirement is **more than 2.0%**, data from **six** replicate
  injections are used.

An RSD criterion of 2.0% or tighter is the common compendial expectation for
assay precision; impurity and content-uniformity methods may carry different,
monograph-specific limits.

## Resolution and Tailing: The Separation Parameters

**Resolution (Rs)** quantifies separation from peak retention times and widths.
Rs of 1.5 corresponds to baseline separation of two roughly equal Gaussian
peaks, which is why ≥ 1.5 is the classic minimum; quantitative impurity methods
frequently demand ≥ 2.0 between the critical pair.

**Tailing factor (T)** measures asymmetry. T = 1.0 is a perfectly symmetric
peak; heavy tailing (T well above 2) usually means active silanol interaction,
a void at the column head, or wrong mobile phase pH, and it distorts
integration of small adjacent impurity peaks.

**Theoretical plates (N)** track column efficiency. A falling N across the
column's life is normal wear; a sudden drop points to a void, contamination, or
a guard column that needed replacing weeks ago.

## Long Sequences: Bracketing Checks

A single passing SST at injection one does not cover 80 injections over two
days. For long sequences, sound practice — and what regulators expect — is
**bracketing system suitability**: periodic check standards interleaved with
samples, with criteria for drift defined in the method or SOP. If a bracketing
check fails, the samples since the last passing check are in doubt.

## When SST Fails

The response is not negotiable in its outline:

1. **Stop.** Do not report sample results from any portion of the run where
   system suitability failed. USP &lt;621&gt; is explicit that failing SST
   invalidates the associated results.
2. **Diagnose** in order of likelihood: mobile phase preparation, standard
   preparation, column condition, instrument (leaks, lamp energy, pump
   ripple), then integration settings.
3. **Correct and re-qualify the system** — the system must pass SST again
   before samples are re-injected.
4. **Document.** An SST failure that affects reported or unreported data is a
   laboratory event; repeated failures or data manipulation around SST is a
   data-integrity problem.

Re-injecting standards until they pass, then quietly continuing the sequence,
is one of the classic FDA 483 / warning-letter patterns in chromatography labs.

## Trend Your SST

Individual passes are binary; the trend is diagnostic. Plot resolution, %RSD,
plate count, and tailing per method over time:

- a slow decline in Rs or N predicts column end-of-life;
- creeping %RSD points to autosampler or pump wear;
- rising tailing tracks column aging or mobile-phase preparation drift.

Trending lets you replace a column on schedule instead of mid-batch at 2 a.m.

## Common Inspection Findings

- Sample results reported from sequences where bracketing SST drifted out.
- SST criteria copied from another method and never justified for this one.
- Standard re-injected repeatedly until a passing set appears, with failed
  injections excluded without rationale.
- No defined response in the SOP for a mid-sequence SST failure.
- Column history untracked, so a degraded column surprises the lab at release
  testing.
- Integration parameters adjusted after SST failure to force a pass.
